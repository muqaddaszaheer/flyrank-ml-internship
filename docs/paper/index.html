Search Intelligence and Content Opportunity Analysis

Google Search Ranking & Discoverability Capstone

Muqaddas Zaheer Ahmad | FlyRank AI Internship – Machine Learning Track

Abstract

This research studies search and content performance using the FlyRank machine learning internship dataset. The goal is to identify useful signals and patterns that can support better content and search decisions. The analysis follows a repeatable machine learning workflow including data exploration, feature preparation, baseline comparison, modeling, validation, and research-claim review. The results are used to develop practical and ranked content recommendations. The findings are intended for decision support and should not be interpreted as proof of Google's ranking algorithm or causal search effects.

Introduction / Problem Statement

Search and content performance can be influenced by multiple content and engagement signals. Looking at these signals individually can make it difficult to decide which pages deserve attention first.

The purpose of this project is to use machine learning and data analysis to identify useful patterns in the available FlyRank data and turn those patterns into practical content recommendations.

Decision supported: The analysis is intended to help prioritize content and search opportunities for further review.

Data

The analysis uses the FlyRank Machine Learning Internship warehouse dataset provided for the internship.

  • Data source: FlyRank internship warehouse dataset.
  • Data was explored and prepared using the workflow developed during the internship.
  • Relevant tables and features were selected according to the research question.
  • Data preparation included checking available fields and excluding information that was not suitable for the analysis.
Public-safe version: Private client names, domains, URLs, search queries, credentials, and raw data exports are not included.

Methodology

The project follows a structured machine learning workflow developed throughout the internship.

  1. Define the research question and decision to support.
  2. Explore the available data and identify useful features.
  3. Prepare the dataset for modeling.
  4. Define the target or action score used in the analysis.
  5. Check for possible feature leakage.
  6. Build a transparent baseline for comparison.
  7. Train and evaluate the selected machine learning approach.
  8. Validate the model using the validation design from the capstone workflow.
  9. Review the strength and limitations of the research claims.
The evaluation compares the model and baseline using the same evaluation setup so that the comparison is meaningful.

Results

The machine learning workflow was compared with a transparent baseline using Precision@50. The documented FlyRank starter workflow reports a baseline Precision@50 of 0.240 and a Random Forest result of approximately 0.740 on the shipped software stack.

Precision@50 Comparison

Baseline 0.240
Random Forest 0.740

This comparison indicates that the machine learning approach can provide substantially stronger prioritization than the simple baseline in the documented workflow.

The Random Forest result can vary across different versions of NumPy and scikit-learn. The result should therefore be interpreted as an evaluation result from the internship workflow rather than as a universal performance guarantee.

Limitations & Honest Framing

  • The analysis is based on the available FlyRank internship dataset.
  • The results show useful patterns and associations, not guaranteed causal effects.
  • The project does not prove how Google's ranking algorithm works.
  • Model results should be treated as decision-support evidence.
  • Additional data and future testing would be needed before making stronger claims.
  • Results may vary depending on the software environment and dataset version.
The findings should be used to support human review and prioritization, not to automatically claim that a specific factor causes a change in search performance.

Ranked Recommendations

  1. Prioritize the strongest opportunities. Focus first on pages or content areas identified by the analysis as having the greatest potential for improvement.
  2. Review important content signals. Investigate the signals identified during the analysis before making content changes.
  3. Apply targeted improvements. Focus recommendations on high-priority opportunities instead of making broad changes everywhere.
  4. Monitor performance after changes. Track future performance to determine whether recommended actions remain useful.
